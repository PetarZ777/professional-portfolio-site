# 🌐 Professional Portfolio Website

A clean, responsive, and professional personal portfolio website built using HTML5, CSS3, and JavaScript. Designed to showcase my resume, skills, and personal projects, this site includes smooth navigation, adaptive design for various devices, and interactive JavaScript elements.

## 🔗 Live Demo

👉 [Visit the Website](https://petarz777.github.io/professional-portfolio-site/)

---

## 💡 Features

- 📄 Resume download button
- 📱 Responsive navigation bar (desktop & mobile)
- 👤 About Me and Contact sections
- 💼 Experience section with visual tech icons
- 🧠 Projects section with live demo and GitHub links

---

## 🛠️ Tech Stack

- **HTML5** — Semantic structure and accessibility
- **CSS3** — Custom styling, layouts, and responsiveness
- **JavaScript** — Toggleable hamburger menu, interactive buttons
- **Media Queries** — Optimized for all screen sizes
- **GitHub Pages** — Free hosting and deployment
